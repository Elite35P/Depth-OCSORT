# Depth-OCSORT
Dairy cows are an important species in livestock farming, providing humans with nutrient-rich dairy products. In dairy farming, cattle tracking is essential for monitoring animal behavior, assessing growth conditions, and detecting environmental anomalies. However, dairy farms feature complex backgrounds and frequent fence and cow-to-cow occlusions, which often lead to frequent false detections and ID loss during tracking. This study proposes a multi-target cattle tracking method based on Depth-OCSORT, comprising two branches: object detection and object tracking. In the object detection branch, YOLOv11x is used as the base model and enhanced with a false positive suppression algorithm to eliminate erroneous bounding boxes and improve the detection precision in cases of overlapping cattle. In the object tracking branch, an improved OCSORT algorithm is introduced by innovatively integrating depth information, transforming two-dimensional positional data into three-dimensional spatial data to enhance cattle distinguishability. Additionally, the Kalman filter is optimized for real-time parameter self-correction, to adapt to rapid morphological changes, such as when cattle turn, thereby improving tracking accuracy. Experiments conducted on a self-built cattle tracking dataset show that the proposed method achieves a multi-object tracking accuracy of 71.298, high order tracking accuracy of 54.026, and identification F1 IDF1 score of 75.386. These represent improvements of 2.5%, 4.99%, and 9.349%, respectively, over baseline methods. In comparative experiments, the proposed method significantly outperforms existing algorithms such as BOTSORT and ByteTrack. This method effectively enables accurate cattle detection and tracking, providing strong technical support for precision dairy farming.
